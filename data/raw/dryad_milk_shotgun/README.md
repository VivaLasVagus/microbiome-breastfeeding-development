# Bacterial composition of the human milk microbiome across lactation

[https://doi.org/10.5061/dryad.rfj6q57j9](https://doi.org/10.5061/dryad.rfj6q57j9)

Longitudinal bacterial composition of human milk across lactation in 15 healthy lactating people as analyzed in a forthcoming publication.

## Description of the data and file structure

Data are organized into two files, Milk_Metagenome_Taxa_Table.csv and Sample_Age_Participant.txt. 

Column definitions for Milk_Metagenome_Taxa_Table.csv:

     Name: Name of bacteria specified by CosmosID

     Kingdom: Taxonomic kingdom

     Phylum: Taxonomic phylum

     Class: Taxonomic class

     Order: Taxonomic order

     Family: Taxonomic family

     Genus: Taxonomic genus

     Species: Taxonomic species

     The 50 following column headers represent individual samples

     Taxonomy ID: ID assigned by CosmosID

     Taxonomic Lineage: Combined taxonomic lineage

Column definitions for Sample_Age_Participant.csv:

     Age (months): Infant age at time of milk sampling in months

     Sample: Sample ID corresponding to columns in Milk_Metagenome_Taxa_Table.csv

     Participant: Participant ID
