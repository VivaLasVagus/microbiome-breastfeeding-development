# microbiome-breastfeeding-development
A reproducible analysis exploring how breastfeeding shapes infant gut microbiome composition and functional pathways, and how those relate to early developmental outcomes. This project is part of my learning and portfolio-building journey in microbiome science, maternal/child health, and early-life development.

--------------
Project Goals
--------------
Examine differences in gut microbiome composition between breastfed and non‑breastfed infants

Explore functional pathways associated with nutrition, immunity, and neurodevelopment

Visualize microbial community structure using R and Power BI

Build statistical models linking microbial features to early developmental outcomes

Practice reproducible workflows using GitHub, R, Quarto, and tidy data principles
